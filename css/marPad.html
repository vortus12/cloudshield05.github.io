Margin vs Padding

① Margin — 요소 바깥 여백 (다른 요소와의 간격)

box A
margin
좌우 30px
box C

② Padding — 요소 안쪽 여백 (테두리~콘텐츠 사이)

콘텐츠

초록 영역 = padding 30px

③ 핵심 차이

Margin 배경색 영향 ✕
요소 밖 공간
음수값 사용 가능
상하 마진 겹침(collapse) 발생
Padding 배경색 영향 ○
요소 안 공간
음수값 사용 불가
box-sizing에 따라 크기 영향

④ 방향별 개별 지정

margin: 10px 20px 10px 20px;   /* top right bottom left */
margin-top: 10px;
padding: 10px 20px;            /* 상하 10px, 좌우 20px */
padding-left: 30px;
