Block vs Inline 요소

HTML 요소의 레이아웃 흐름을 이해하는 핵심 개념

요소 유형

블록(Block) 요소

  • 항상 새 줄에서 시작
  • 가능한 전체 너비를 차지
  • width / height 지정 가능
  • 상하 margin 적용 됨
  • 내부에 블록 + 인라인 모두 포함 가능
<div> <p> <h1>~<h6> <ul> <ol> <li> <table> <form> <header> <section>

인라인(Inline) 요소

  • 텍스트 흐름 안에서 이어짐
  • 콘텐츠 크기만큼만 차지
  • width / height 무시됨
  • 상하 margin 적용 안 됨
  • 내부에 인라인 요소만 포함 가능
<span> <a> <strong> <em> <img> <input> <label> <button> <code>

인라인 블록(Inline-Block)

  • 줄 바꿈 없이 가로로 이어지면서 — width / height 지정 가능 (블록 + 인라인의 장점 결합)
  • display: inline-block 으로 설정 — 버튼, 나란히 배치할 박스 등에 자주 활용

비교표

특성 Block Inline Inline-Block
줄 바꿈 O X X
기본 너비 부모의 100% 콘텐츠만큼 콘텐츠만큼
width / height 적용 됨 무시됨 적용 됨
상하 margin 적용 됨 적용 안 됨 적용 됨
내부 포함 가능 블록 + 인라인 인라인만 인라인만

시각적 예시

실제 브라우저에서 요소들이 이렇게 배치됩니다

Block — 세로로 쌓임

<div> 블록 요소 1 — 전체 너비 차지
<div> 블록 요소 2 — 새 줄에서 시작

Inline — 가로로 이어짐

<span> 인라인 1 <span> 인라인 2 <span> 인라인 3

Inline-Block — 가로로 이어지면서 크기 지정

120×60
120×60
120×60

코드 예시

HTML / CSS
<!-- 블록: 세로로 쌓임 -->
<div>박스 1</div>
<div>박스 2</div>

<!-- 인라인: 가로로 이어짐 -->
<span>텍스트 1</span>
<span>텍스트 2</span>

<!-- 인라인 블록: 가로로 이어지면서 크기 지정 가능 -->
<span style="display: inline-block; width: 100px; height: 50px;">
  버튼
</span>

/* CSS로 display 변경 */
span { display: block; }       /* 인라인 → 블록 */
div  { display: inline; }      /* 블록 → 인라인 */
div  { display: inline-block; } /* 블록 → 인라인블록 */
⚠️ 규칙 위반 주의: 블록 요소를 인라인 요소 안에 넣으면 안 됩니다. 예를 들어 <p> 안에 <div>를 넣거나, <a> 안에 <h1>을 넣는 것은 HTML 명세 위반으로, 브라우저가 예상치 못한 방식으로 렌더링할 수 있습니다.
