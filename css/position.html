CSS Position 5가지

① static — 기본값

모든 요소의 기본 position. top/left/right/bottom/z-index 값이 무시됩니다. 문서 흐름대로 배치됩니다.

static

② relative — 자기 자신 기준 이동

원래 있던 자리를 유지하면서 top/left 값만큼 시각적으로 이동합니다. 빈 자리(점선)는 그대로 남습니다.

원래 위치
relative
top:20 left:30

③ absolute — 가장 가까운 positioned 부모 기준

문서 흐름에서 완전히 빠져나옵니다. position: relative/absolute/fixed인 가장 가까운 조상을 기준으로 위치가 결정됩니다.

기준 부모
(relative)
absolute
top:16 right:20

④ fixed — 뷰포트 기준 고정

스크롤해도 항상 같은 자리에 붙어 있습니다. 뷰포트(브라우저 화면)를 기준으로 위치가 결정됩니다. 우측 하단의 주황 버튼이 예시입니다.

👉 화면 오른쪽 아래의 fixed 버튼을 확인하세요.
페이지를 스크롤해도 항상 같은 위치에 표시됩니다.
position: fixed; bottom: 24px; right: 24px;

⑤ sticky — 스크롤 시 특정 위치에 달라붙음

평소에는 static처럼 흐르다가, 스크롤이 지정한 위치에 닿으면 fixed처럼 고정됩니다. 아래 목록을 스크롤해보세요.
